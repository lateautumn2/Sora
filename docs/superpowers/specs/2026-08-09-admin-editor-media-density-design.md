# 后台编辑器与媒体卡片密度调整设计

## 目标

在不改变文章保存、删除、媒体预览与地址复制逻辑的前提下，修复编辑器顶栏贴边问题，降低不常用 SEO 字段的视觉干扰，并提高媒体库的信息密度。

## 范围

本次调整包含四项：

1. 恢复文章与页面编辑器顶部工具栏的四周内边距。
2. 将文章设置中的 SEO 设置默认折叠。
3. 将已有内容的“移至回收站”操作移动到顶部工具栏，与“保存内容”并列。
4. 缩小媒体图片卡片，缩略图固定高度并使用 `object-fit: cover` 裁切；弹窗预览继续完整显示原图。

不修改内容动作接口、字段名称、媒体存储、删除确认流程或公开站点样式。

## 编辑器顶部工具栏

顶部工具栏继续使用现有 `AdminToolbar`，保持吸顶行为。样式恢复水平内边距，使返回链接和操作按钮不再贴近边框。

操作区包含：

- “保存内容”：继续通过 `form="content-editor-form"` 提交主编辑表单。
- “移至回收站”：仅编辑已有文章或页面时显示，保留独立的 `trashContentAction` 表单及 `id`、`kind` 隐藏字段，避免嵌套表单。

回收站按钮使用危险色的共享按钮样式。页面底部不再渲染重复删除入口。

## SEO 默认折叠

SEO 字段使用原生 `<details>` 和 `<summary>` 组成折叠区，默认不设置 `open`，因此首次进入编辑器时保持关闭。

SEO 标题、SEO 描述和规范链接仍在 DOM 与主表单中，折叠不会改变字段值、表单提交或移动端设置弹窗的数据桥接。用户点击“SEO 设置”后可展开编辑。

## 媒体卡片

媒体网格在宽屏显示四列，中等桌面显示三列，平板显示两列，手机显示一列。

缩略图采用固定高度和 `object-fit: cover`：

- 卡片列表只承担快速识别用途，可裁切图片边缘。
- 点击缩略图仍打开现有预览弹窗，弹窗内使用 `object-fit: contain` 完整展示原图。
- 卡片正文缩小间距和内边距，但保留文件名、尺寸、大小、删除操作与地址类型标签。

## 响应式与可访问性

- 顶部操作区允许换行，窄屏下不得造成水平溢出。
- SEO 折叠标题必须可通过键盘聚焦和切换。
- 删除操作仍使用明确的按钮文字和危险色，不以纯图标替代。
- 媒体预览按钮保留现有可访问名称。

## 验证

新增或扩展自动化测试，覆盖：

- 编辑已有内容时，保存与回收站按钮同时位于顶部工具栏，底部无重复删除入口。
- 新建内容不显示回收站按钮。
- SEO 设置初始折叠，展开后字段可编辑且正常提交。
- 工具栏计算样式具有水平内边距。
- 媒体网格宽屏为四列，缩略图固定高度并使用 `cover`，预览弹窗仍完整展示原图。
- 运行编辑器与媒体专项测试、全量单元测试、类型检查和生产构建。
